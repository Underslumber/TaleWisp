# Install TaleWisp

This directory is a portable Codex plugin, not a manuscript vault.
In the source repository, follow [installation instructions](../docs/INSTALL.md).
Register the repository as a local marketplace and install TaleWisp through Codex plugin settings.
The release archive includes marketplace metadata at its root. Extract the entire archive.
Python 3 is required; set TALEWISP_PYTHON to its executable when Python is not on PATH.
Restart the chat after installation and verify MCP initialize/tools/list.
Select your own vault explicitly. Google operations additionally require a connected Google Drive plugin.
StoryArt is optional and installed separately only on explicit request.
