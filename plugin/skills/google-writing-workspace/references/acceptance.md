# First author session

Prerequisite: the Google Drive plugin is installed, connected to the right account, and exposes target reads; browser access is separate. The local TaleWisp helpers alone cannot access Google files. Source installation and installed plugin are separate copies; reload updated tools/skills before testing.

Use an existing working Doc or an author-requested copy, not an unrelated manuscript. Useful requests:

> Используй TaleWisp. Найди мой документ «Глава 3», прочитай выбранную сцену и все комментарии с ответами. Покажи минимальную редакцию по моему замечанию в чате; документ пока не меняй.

> Внеси показанную замену в указанную вкладку этого документа. Оставь её нативным предложением; сохрани оформление и остальные правки.

> Замени этот фрагмент напрямую, без предложений. Сохрани оформление и остальные правки.

> Оставь эту замену как нативное предложение Google Docs, чтобы я мог принять или отклонить её.

> Свяжи сцену с существующим индексом Sheets: события, состояния персонажа и знания на этот момент. Прочитай нужные строки; новый файл не создавай.

| Check | Acceptance |
|---|---|
| Discovery/read | Correct document/tab; source revision; complete comment pages/replies; exact quote |
| Preview | Preserved events, knowledge and selected voice; manuscript unchanged |
| Direct edit | Explicit direct-edit request; fresh readback matches replacement with surrounding style preserved |
| Native suggestion (revision default) | Saved pending IDs bound to exact original/replacement, native accept/reject controls and pending readback; local plan is not a saved suggestion |
| Manuscript comment | Saved native range-anchored thread; exact quote and editor linkage verified through supported API/editor evidence; quotedFileContent or body quote alone is insufficient |
| Reply | Saved reply under the verified live target thread |
| Linked context | Bounded live rows with evidence/revision; draft facts remain draft |

Existing manuscript revision requests default to native pending suggestions; «Внеси исправление» alone does not permit direct editing. Explicitly requested previews remain previews and new requested text insertions retain their own product. Browser access requires separate author authorization; never open or use a personal browser silently. If native suggestion or range-anchored comment saving is unavailable, identify the unfinished operation. A prepared preview is not acceptance and must not replace the requested saved product automatically. Direct application or an alternative product requires the author's explicit choice; already authorized supported connector actions need no additional confirmation. Existing author samples prove their observed state, not our write. Do not require calibration to start writing. Quality of author voice still needs the author's assessment; helper tests and saved UI cards prove their own layers only.
