# Работа в TaleWisp

Выберите автора, серию и книгу в верхней части рабочего пространства. Этот выбор задаёт область текстов, заметок, базы знаний и диалога агента. Ранее созданные записи без привязки остаются доступны в общем списке.

## Тексты и прогресс

В обзоре книги открывайте исходные главы и отдельные разборы сцен. Это разные материалы. Исходник отображается для чтения; для редактирования сначала создайте локальный черновик. Локальные черновики сохраняются автоматически с историей версий.

Прогресс строится по фактическому количеству слов и указанному вами состоянию текста. Цель в словах задаётся вручную; без цели приложение не изображает процент готовности. Заметки можно просматривать в текущей книге или общим списком.

## Знания и ссылки

Карточки показывают обычный текст, заголовки и переходы на связанные записи. Служебная разметка скрыта в основном чтении. Поиск работает по выбранной базе серии. Если название ссылки неоднозначно, выберите подходящую запись; приложение не выбирает канон за автора.

Для контекста агента отметьте необходимые источники. Цитаты и ссылки в его ответах позволяют вернуться к записи базы. Перед передачей частных материалов внешней модели учитывайте выбранный набор источников.

## Агент и изменения

Агент использует подписку ChatGPT через локальный Codex. Он получает инструменты TaleWisp для анализа, подготовки базы и предложений текста. Для записи изменения создаётся предложение: прочитайте точный результат, затем примените или отклоните его. Изменившийся после подготовки источник требует нового предложения. Сохранение предложения само по себе не изменяет канон или рукопись.

Написание по стилю использует подтверждённые материалы выбранного автора и серии. Исключение стиля в конкретной серии сохраняется, пока автор явно не задаст другое решение. Автоматическая калибровка и перенос стиля другого автора не запускаются.

Google Docs подключается отдельно через [Google OAuth](GOOGLE-OAUTH.md). Инструменты планирования Google и реальные облачные действия различаются: до авторизации чтение и сохранение в Docs недоступны. Правки существующего документа сохраняются нативными предложениями с проверкой версии и диапазона.
