# TaleWisp: исследование интерфейса, 14 октября 2026

Автор отверг прежний вид: слишком маленький интерфейс, огромные пустые поля, отсутствие убедительной адаптации. Новый запрос прямо разрешает исследование и переработку фронтенда. Старые визуальные оценки отменены.

| Изучено по первичному источнику | Подход | Применение |
|---|---|---|
| [Ulysses](https://help.ulysses.app/en_US/first-steps-library-editor) | Библиотека, список документов, редактор; переключение числа панелей | Навигация и текст остаются единым рабочим пространством; на телефоне редактор первичен |
| [Scrivener Inspector](https://www.literatureandlatte.com/blog/get-to-know-the-scrivener-inspector) | Binder, Editor, Inspector; заметки и версии рядом с выбранным документом | На широком экране помощник и инструменты занимают функциональную боковую панель |
| [Novlr](https://help.novlr.org/en/category/writing-1cf23qy/) | Чистая панель, инструменты по выделению, версии в боковой панели | Действия с активным текстом рядом с редактором; вторичные действия раскрываются по запросу |
| [Tailwind responsive](https://tailwindcss.com/docs/responsive-design) | Mobile first, условные layout при breakpoint | Раздельные компоновки телефона, планшета и компьютера, не простое уменьшение всего UI |

| Библиотека | Оценка для текущего клиента |
|---|---|
| [Radix](https://www.radix-ui.com/primitives/docs/components/dialog) | Доступные React-примитивы; полная миграция текущего сохранения/DOM неоправданна для редизайна |
| [Shoelace](https://shoelace.style/), [Web Awesome](https://webawesome.com/docs/theming-overview) | Компоненты и темы; изучены как дизайн-система, не подключать CDN к приватному приложению |
| [Lucide](https://lucide.dev/guide/lucide) | Единые SVG-иконки, пригодные для локальной поставки |

Выбраны локальные SVG-иконки, семантические тёмные токены, нативные HTML-контролы/диалоги. Это сохраняет автономный запуск и существующие API. Цветовая основа — найденный авторский логотип: голубой дух, золотое перо и книга, исходный PNG используется без правки.

Проверки результата: реальные широкие и мобильные viewport, вертикальная прокрутка панелей, сохранение текста/выделения, переходы между режимами. Наличие media query само по себе не является подтверждением адаптивности. Работа клавиатуры на физическом телефоне требует отдельной проверки.
