## Ограничения

«Писать по каркасу» в текущем нативном мосте недоступно: runtime не предоставляет доверенную проверку токенов, окна модели и скрытого контекста. Сервер возвращает 503 до запуска хода, браузер показывает причину. Обсуждение с согласованным каркасом доступно. Положительная ветка письма проверена только синтетическим host-адаптером в тестах.

Живая генерация внешней моделью, доступ к Google API, запись авторской рукописи и развёртывание рабочего сервиса не выполнялись. Фикстурный runner не является живой моделью. Авторская визуальная приёмка не заявлена.
