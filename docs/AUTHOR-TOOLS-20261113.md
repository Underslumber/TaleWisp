# Инструменты автора и стили оформления

Документ описывает возможности веб-клиента, добавленные 13 ноября 2026 года.

## Инструменты автора

Меню открывается кнопкой с сеткой в шапке. Те же команды доступны в поиске по `Ctrl+K`.

| Инструмент | Что делает | Откуда берёт данные |
| --- | --- | --- |
| Поиск по проекту | Ищет по главам рабочей рукописи, локальным черновикам, заметкам, карточкам базы знаний и командам | `GET /api/tools/search` |
| Статистика и цели | Слова в книге и за день, серия дней, цели по книге и на день, график за 30 дней | `author-tools.sqlite`, таблица `writing_days` |
| История версий главы | Версия создаётся при сохранении рабочей рукописи; правки в течение десяти минут дополняют одну версию. Версию можно сравнить с текущим текстом, закрепить и восстановить | таблица `chapter_versions`, хранится до 120 версий на главу |
| Проверка непрерывности | Сверяет открытую главу с контрактами непрерывности серии и показывает находки рядом с цитатой | инструмент плагина `talewisp_continuity_check` |
| Хронология | События и сцены по порядку истории или повествования, с фильтром по персонажу | контракты непрерывности в папке серии |
| Сборка книги | EPUB, DOCX и FB2 из рабочей рукописи с сохранением жирного, курсива, подчёркивания и зачёркивания | `GET /api/tools/export` |
| Журнал агента | Применённые предложения агента с отменой, если файл с тех пор не менялся | журнал предложений рабочего пространства |
| Ролевая сцена | Список запущенных веток, их состояние и сыгранные ходы; продолжение и оформление передаются агенту | `talewisp_roleplay_status`, `talewisp_roleplay_packet` |
| Режим фокуса | Оставляет на экране только текст. Клавиша `F9`, выход по `F9` или `Esc` | только клиент |
| С чего начать | Три шага для новой книги; открывается сам при первом запуске | только клиент |

При наведении на имя персонажа или места в главе появляется краткая карточка из базы знаний.
При потере связи клиент показывает полосу «нет связи» и досылает несохранённые правки после восстановления.

Клиент ничего не пишет в канон в обход предложений: ролевая панель только читает состояние ветки,
а запуск и ходы остаются действиями агента, которые автор применяет сам.

## Стиль и палитра

Палитра и стиль отрисовки выбираются отдельно. Палитра задаёт цвета, стиль задаёт рамки, орнаменты,
форму узлов карты и шрифт заголовков.

- Палитры: ночь, гримуар, бычья кровь, луна, обсидиан, пергамент, sci-fi, hi-tech, пустошь.
- Стили: таро, рукопись, гравюра, машинопись, sci-fi, hi-tech, пустошь. Значение «авто» берёт родной стиль палитры.

Страница-образец со всеми элементами интерфейса: `/style-guide.html`.

Темы учитывают системные настройки «меньше движения» и «повышенный контраст». Основной, приглушённый
и тихий текст во всех палитрах имеет контраст не ниже 4.5:1 к фону.

## Проверки

Тесты запускаются на GitHub при каждом изменении: `.github/workflows/tests.yml` (Windows, Node 24, Python 3.13).
Нейтральные файлы для тестов создаёт `web-client/scripts/prepare-test-fixtures.mjs`.
