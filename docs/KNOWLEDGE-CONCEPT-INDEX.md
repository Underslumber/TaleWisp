# Индекс понятий

Карта WebUI и поиск помощника используют один производный индекс серии в
`web-client/.data/knowledge-outlines/<series-id>.json`. Индекс содержит понятия,
их вложенность, полные пояснения с версиями, источники и подтверждённые связи.
Приватный индекс нельзя включать в публичную поставку.

Помощник может искать без браузера и без изменения авторских файлов:

```powershell
python scripts/search_knowledge_outline.py "термин или фраза" --index "путь к индексу серии.json"
```

Результат содержит ID, путь в иерархии, определение, остальные версии и точные
ссылки на источники. Совпадение полного названия или алиаса имеет приоритет
перед упоминанием в другом тексте. По умолчанию возвращаются десять результатов;
`--limit` принимает значения от 1 до 100.

`parentId` задаёт только вложенность. Связи `related` имеют отдельное основание;
цитата из источника отличается от простого упоминания. Историческое описание,
план и авторское уточнение нельзя автоматически считать одним текущим правилом.

При объединении подтверждённого дубля сохраняются все определения, версии,
источники и дочерние понятия. Старый ID остаётся в `redirects`, прежнее имя —
в `aliases`. Переименование подписи не изменяет текст источника.

Индекс перестраивается только из явно выбранной спецификации:

```powershell
python scripts/build_knowledge_outline.py --spec "спецификация.json" --output "кандидат.json"
```

Перед заменой рабочего индекса проверяются все прежние определения и источники,
полный реестр понятий, циклы, перенаправления и поиск. Само перестроение индекса
не изменяет канон, рукописи и исходные авторские файлы. Отсутствующие сведения
не дополняются догадками.
