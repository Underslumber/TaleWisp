## Анимации и компоненты

| Источник | Что подходит | Цена и ограничение |
|---|---|---|
| [View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API) | Карточка превращается в следующий уровень | Нативно; feature detection и fallback обязательны |
| [Web Animations](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate) | Прерываемые локальные переходы, управление временем | Хорошо соответствует существующему ESM; нужна собственная координация состояния |
| [Motion layout](https://motion.dev/docs/react-layout-animations) | Shared element через `layoutId` | Удобно в React; React-миграцию и платные дополнительные компоненты не считать бесплатной необходимостью |
| [GSAP Flip](https://gsap.com/docs/v3/Plugins/Flip/) | FLIP-переходы и сложная пространственная композиция | Независим от React; проверить лицензию выбранного релиза и реальную необходимость |
| [Embla](https://www.embla-carousel.com/) | Точное свайповое управление лентой | На странице есть stable 8.6.0 и prerelease 9; не выбирать prerelease автоматически. Для простого scroll-snap не обязателен |
| [Base UI](https://base-ui.com/react/overview/quick-start) | Доступные меню, диалоги, popover и drawer | Для React. Стили TaleWisp проектируются отдельно |
| [React Bits](https://reactbits.dev/) | Визуальные паттерны карточек и взаимодействий | Источник компонентов; отбирать отдельные элементы, проверять их условия и зависимости |
| [Animata](https://animata.design/) | Идеи интерактивных компонентов | React; нельзя переносить библиотечный внешний вид целиком вместо собственной системы |
| [Libraries.dev](https://libraries.dev/) | Световой акцент, индикатор работы агента | React; каталог заявляет MIT для пяти библиотек, Pro отдельно платный. Декоративные эффекты не должны утяжелять редактор |
| [Emil Kowalski](https://emilkowal.ski/ui/7-practical-animation-tips) | Практические правила отклика и easing | Методические ориентиры; без неконтролируемого копирования чужих эффектов |

Предпочтение для первого решения: CSS scroll-snap + нативные прерываемые переходы. Motion или GSAP выбирать при доказанном выигрыше. Не устанавливать все найденные модули одновременно.

## Доступность

[W3C SC 2.3.3](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html) объясняет возможность отключения несущественного движения. Это AAA-критерий; reduced-motion здесь принят как требование проекта, без заявления о полной сертификации WCAG. Числовые пороги контраста, reflow и touch targets взяты из сохранённого `web-client/UX.md` и проверяются на новом результате.

Подробное ТЗ и матрица сохранения функций: [WEB-REDESIGN-20261021.md](WEB-REDESIGN-20261021.md).
