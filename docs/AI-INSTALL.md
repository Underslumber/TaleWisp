# Короткая инструкция для ИИ

Скопируйте это сообщение в Codex или StoryArt:

```text
Установи TaleWisp из https://github.com/Underslumber/TaleWisp.
Проверь существующую установку, совместимость и Python 3.10+.
Добавь marketplace Underslumber/TaleWisp с ref v0.6.1 и установи
talewisp@underslumber-talewisp штатным Codex CLI.
Если Git недоступен, скачай talewisp-0.6.1.zip и SHA256SUMS.txt
из релиза v0.6.1, проверь SHA-256, распакуй в отдельный каталог,
добавь его как локальный marketplace и установи плагин.
Не заменяй другие плагины, настройки, рукописи, базы и профили стиля.
Проверь квитанцию установки. Создай отдельную новую задачу TaleWisp,
передай выбранный локальный путь и проверь загрузку навыков и MCP,
включая talewisp_build_series_base.
Затем создай мою собственную базу по приложенным FB2 штатным механизмом:
спроси псевдоним автора, прочитай источники, собери девять слоёв анализа,
выполни проверки и независимое ревью. Если книг нет, попроси приложить их.
Не загружай мои книги, базу знаний или профиль стиля в GitHub.
Калибровку стиля запускай только по моему запросу.
```

Плагин содержит механизм и пустые шаблоны. Готовые базы произведений,
личные профили стиля и авторские фрагменты в дистрибутив не входят.
Вход в аккаунт и системные диалоги разрешений остаются за пользователем.
Отсутствие CLI или инструментов нужно назвать явно: инструкция сама по себе
не считается установкой. Для создания новой задачи использовать штатные
инструменты Codex; только готовый `threadId` подходит для дальнейших вызовов.
