# TaleWisp: правила для Claude

TaleWisp состоит из плагина Codex на Python (`plugin/`) и веб-клиента на Node 24 без зависимостей (`web-client/`).
С автором общаемся по-русски. `README.md` служит визитной карточкой проекта, его нельзя перезаписывать.

## Оркестрация

Главная сессия работает архитектором: разбирается в задаче, делит её на части, проверяет результат и отвечает за итог.
Саму работу она по возможности отдаёт субагентам из `.claude/agents/`.

| Субагент | Модель | Когда звать |
| --- | --- | --- |
| `tw-scout` | haiku | Найти место в коде, перечислить файлы, собрать факты. Только чтение. |
| `tw-implementer` | sonnet | Оформленная задача с понятным результатом: правка, тест, документ. |
| `tw-test-runner` | haiku | Запустить тесты и вернуть только упавшие с причиной. |
| `tw-reviewer` | sonnet | Независимая проверка готового изменения перед слиянием. Только чтение. |

Архитектор не делегирует: выбор решения, изменения контрактов и схем данных, всё, что касается секретов и доступа,
слияние в main, действия на машине автора.

### Задание субагенту

Субагент не видит переписку, поэтому задание должно быть самодостаточным:

1. Цель одной фразой и зачем она нужна.
2. Файлы, которые можно менять, и файлы, которые трогать нельзя.
3. Что уже известно: точные пути, имена функций, найденная причина.
4. Критерий готовности, который можно проверить командой.
5. Формат ответа: что сделано, что проверено и чем, что осталось.

Независимые задания запускаются параллельно, если они не меняют одни и те же файлы. Зависимые идут по очереди.
Результат субагента считается сырьём: архитектор читает изменение и запускает тесты, прежде чем принять его.

## Границы

- Файлы Codex не трогаем без команды автора: `plugin/scripts/roleplay*.py`, `roleplay_memory.py`, всё с именем `living-world`, `vendor/worldx`.
- В `web-client/public/app.js`, `index.html` и `web-client/server.mjs` добавляем импорты, маршруты и кнопки отдельными строками и не переписываем `closeSpecial()`, блок переключения видов и блок статики.
- Политика содержимого страницы запрещает встроенные стили и скрипты и внешние ресурсы.
- Не вызываем `alert`, `confirm`, `prompt`.
- Многие файлы хранятся с окончаниями CRLF, их нужно сохранять.

## Проверки

```
node web-client/scripts/prepare-test-fixtures.mjs
cd web-client && node --test tests/*.test.mjs newtests/*.test.mjs tests-ui/*.test.mjs tests-agent/*.test.mjs tests-google/*.test.mjs
python -m pytest -q -p no:cacheprovider tests
```

Нужен Node 24. На Linux один тест `storyart-project` падает из-за путей Windows, на Windows он проходит.
Те же проверки идут на GitHub при каждом изменении.
